## Test APIs

### 1. Model Explainability
By default the response is JSON with both outputs: `report_data` (metrics,
feature importance, chart data, data analysis) and `html_report` (the page).
`output_format=html` returns only the page, `output_format=json` only the data.
```bash
# Default: HTML report + JSON data, saved side by side
curl -X POST "http://localhost:5000/explain-model" \
  -F "model_file=@./path/to/your_model.zip" \
  -F "data_file=@./path/to/your_data.csv" \
  -F "user_level=expert" \
  -o response.json
jq -r '.html_report' response.json > model_report_expert.html
jq '.report_data' response.json > model_report_expert.json

# HTML page only (beginner mode)
curl -X POST "http://localhost:5000/explain-model" \
  -F "model_file=@./path/to/your_model.zip" \
  -F "data_file=@./path/to/your_data.csv" \
  -F "user_level=beginner" \
  -F "output_format=html" \
  -o model_report_beginner.html

# JSON data only
curl -X POST "http://localhost:5000/explain-model" \
  -F "model_file=@./path/to/your_model.zip" \
  -F "data_file=@./path/to/your_data.csv" \
  -F "output_format=json" \
  -o model_report.json
```

### 2. Model Info (JSON)
```bash
curl -X POST "http://localhost:5000/explain-model/info" \
  -F "model_file=@./path/to/your_model.zip" \
  -F "data_file=@./path/to/your_data.csv"
```

### 3. EDA Report
```bash
curl -X POST "http://localhost:5000/explain-model/eda" \
  -F "data_file=@./path/to/your_data.csv" \
  -F "user_level=expert" \
  -o eda_report.html
```

### 4. Data Analysis
```bash
# HTML report
curl -X POST "http://localhost:5000/analyze-data" \
  -F "csv_file=@./path/to/your_data.csv" \
  -F "user_level=expert" \
  -o data_analysis.html
```

## Container Management

```bash
# View logs
docker logs xai-api

# Stop container
docker stop xai-api

# Start container
docker start xai-api

# Remove container
docker rm xai-api

# Full rebuild
docker stop xai-api && docker rm xai-api && \
docker build -t xai-api . && \
docker run -d --name xai-api -p 5000:5000 xai-api
```

## Available Endpoints

| Endpoint | Method | Parameters | Description |
|----------|--------|------------|-------------|
| `/health` | GET | - | Health check |
| `/explain-model` | POST | model_file, data_file, user_level, output_format | Model explainability (HTML + JSON by default) |
| `/explain-model/info` | POST | model_file, data_file | Model info (JSON) |
| `/explain-model/eda` | POST | data_file | EDA report |
| `/analyze-data` | POST | csv_file, user_level | Data analysis (HTML) |
